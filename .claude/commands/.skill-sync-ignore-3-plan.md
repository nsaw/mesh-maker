Generic (project-neutral) variant for mesh-maker.

thoughtmarks' 3-plan carries the SAME frontmatter identity but is iOS-tailored
(mandatory `ios-pro` invocation, `.claude-cache/plans/` output path). Because the
identities match, the divergence guard will NOT stop a tm -> mesh sync — this pin
is the only thing preventing re-contamination of a Rhino/CNC repo with iOS
instructions. That contamination happened once already (found 2026-07-24).

Remove this file only if mesh-maker genuinely wants thoughtmarks' iOS content.
